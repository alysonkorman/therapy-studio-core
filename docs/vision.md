# Therapy Studio Vision

## Purpose

Therapy Studio helps me quickly find something clinically meaningful, effective, and engaging for this child in this moment.

It is built for my own clinical practice. It does not need to function like an EHR or serve other therapists.

## Core Problem

During a session, I may know that something useful exists but cannot retrieve it quickly enough.

Therapy Studio should help me respond when:

- a child is shutting down
- rapport feels weak
- a child keeps saying “I don’t know”
- the original session plan is not working
- I need something engaging immediately
- I remember the child’s interests but not the right activity
- I want to reuse something that worked previously

## Core Design Principles

1. Multiple entry points are intentional.
2. The app should adapt to how I think and feel that day.
3. Resources should be connected rather than separated into silos.
4. Every resource should quickly answer:
   - Should I use this now?
   - How do I use it?
   - What should I use with it?
5. The system should preserve what I learn from using resources.
6. Kids wanting to participate is a primary measure of success.
7. Clinical meaning and engagement must exist together.
8. The interface should be fast enough to use during a live session.
9. The app should remain customizable without making ordinary use complicated.
10. New features should connect to the same underlying system.

## Main Areas

- Dashboard
- Prompt Library
- Intervention Library
- Games and interactive tools
- Profiles
- Worksheet Builder
- Workbook and psychoeducation builder
- Scene Builder
- Sand Tray
- Dollhouse
- Two-player session mode

## Core Resource Model

A resource may be:

- a prompt
- an activity
- an intervention
- a game
- a worksheet
- a visual
- a psychoeducation sheet
- a workbook section
- a source document
- a clinical note or adaptation

Resources may connect through:

- Works well when
- Interests
- Goals
- Ages
- Diagnoses
- Duration
- Setting
- Materials
- Use With
- Related resources
- Source
- Supporting research
- My notes
- Clinical wins
- What did not work

## North Star

I want to always have something I can turn to very quickly that is clinically meaningful, effective, and makes kids want to participate.
