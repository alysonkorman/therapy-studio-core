# Session Mode

## Session Profiles

Session Profiles provide reusable, generic context for preparing a session. They are
not client charts or clinical records. The active profile survives route navigation,
but selecting it does not alter Current Session.

“Use Profile for Current Session” explicitly fills empty fields by default or replaces
matching fields after confirmation. Profile and Current Session data remain independent
afterward: editing or clearing either one does not update the other.

Profiles may map a generic label, age range, diagnoses, goals, interests, current
presentation defaults, preferred session length, telehealth setting, available
materials, communication and sensory preferences, regulation strategies, reading and
writing tolerances, humor, motivators, strengths, things to avoid, and non-identifying
reminders. Context without a safe direct Current Session field remains profile-only.

Resource compatibility labels are descriptive only. They do not change search ranking,
create recommendations, or claim that a Resource is clinically appropriate.
